把下载交给 AriaUI

在这里设置接管规则和确认交接结果。下载进度与文件管理请在 AriaUI 中查看。

连接

扩展 ID：

Windows / Linux 需要注册 com.ariaui.downloader 宿主，且允许来源必须匹配上面的扩展 ID。

自动接管

仅接管能匹配到 GET 请求的下载。POST、认证头、范围请求、无痕和其他扩展的下载会跳过。

使用逗号或换行分隔。域名按实际下载地址匹配，支持 *；排除优先。允许列表与大小条件需要同时满足。

手动发送

一次发送一个链接。HTTP 链接以 GET 提交，不携带浏览器 Cookie；需要登录的下载请在网页链接上右键选择“用 AriaUI 下载（携带 Cookie / Referer）”或使用自动接管。

交接记录

“已交给 AriaUI”表示任务已创建。结果未知时不会自动重发，最多自动查询三次。 选择“继续浏览器”前，请先确认 AriaUI 中没有重复任务。
